# 🎨 Diseño de Interfaces Web – Cuaderno DAW

Bienvenido a mi cuaderno de trabajo de la asignatura **Diseño de Interfaces Web** del ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

Este repositorio recoge todos los ejercicios, prácticas y proyectos realizados a lo largo del curso, organizados por trimestres y unidades didácticas.

---

## 📌 Descripción

Este proyecto tiene como objetivo servir como:

* 📚 Repositorio de aprendizaje
* 🧠 Refuerzo de conceptos de diseño web
* 💻 Muestra de habilidades en HTML, CSS y JavaScript
* 🚀 Seguimiento de mi evolución como desarrolladora

A lo largo del curso se han trabajado aspectos clave como:

* Maquetación web con **HTML5**
* Estilos avanzados con **CSS3**
* Diseño responsive
* Uso de **Flexbox** y **Grid**
* Introducción a **JavaScript**
* Frameworks como **Tailwind CSS**
